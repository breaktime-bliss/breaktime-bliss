# Breaktime Bliss

Static website for Breaktime Bliss, a home-based healthy bakery in Brampton, Ontario (Instagram: [@breaktime.bliss](https://www.instagram.com/breaktime.bliss/)).

- `index.html` – the whole site (no build step)
- `assets/` – logo and product photos

Hosted on GitHub Pages. The order form posts to FormSubmit, which emails each order request.
